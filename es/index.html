FÓRMULA

ζ = c / (2 √(m k))

Condiciones de aplicación

c≥0; m,k>0. Sistema lineal de un grado de libertad con amortiguamiento viscoso. No se aplica a fricción seca ni a amortiguadores no lineales. El coeficiente b de la referencia se llama c aquí.

Los valores mostrados son aproximaciones de coma flotante. No se calculan la incertidumbre de medida ni los factores de seguridad de diseño.
